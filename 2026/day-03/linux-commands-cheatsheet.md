# Linux Commands Cheat Sheet

## File System Commands

| Command | Usage |
|---|---|
| `pwd` | Show current directory |
| `ls` | List files and folders |
| `ls -la` | Show hidden files |
| `cd` | Change directory |
| `mkdir` | Create folder |
| `touch` | Create empty file |
| `cp` | Copy files |
| `mv` | Move or rename files |
| `rm` | Delete file |
| `cat` | View file content |

---

# Process Management Commands

| Command | Usage |
|---|---|
| `ps` | Show running processes |
| `ps aux` | Detailed process list |
| `top` | Live process monitoring |
| `kill PID` | Stop process |
| `kill -9 PID` | Force stop process |
| `jobs` | Show background jobs |
| `bg` | Run process in background |

---

# Networking Commands

| Command | Usage |
|---|---|
| `ping google.com` | Check internet connectivity |
| `ip addr` | Show IP address |
| `curl google.com` | Test website/API response |
| `hostname` | Show system hostname |
| `ssh user@ip` | Connect remote server |

---

# Key Learnings

- Linux commands help in daily troubleshooting
- Process commands are useful for monitoring applications
- Networking commands help test connectivity
- File system commands are used regularly in DevOps
